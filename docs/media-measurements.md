# 영상 깜빡임·전사 군말 후보 측정 — F15·F16

**현재 구현 상태:** 자체 실행 텍스트 코칭과 음성 전사의 첫 구현이 추가됐다. 아래 전체 기획의 완료 조건과 구현된 부분은 [구현 범위](local-ai-implementation.md)에서 구분한다. 외부 AI Gateway와 브라우저 실시간 음성 인식은 제거/비활성화했다.


2026-10-29 사용자 지시로 얼굴 분석의 범위를 변경했다. 감정·긴장·자세·발표 점수는 판정하지 않는다. F15는 영상의 눈 깜빡임 측정, F16은 기존 파일 불러오기·선택 AI 전사에 군말 후보 집계를 연결한 기능이다. F1–F14의 번호·기존 S1–S4는 유지한다.

## 사용 흐름

- 웹캠으로 연습을 녹화한 뒤 결과 화면의 **눈 깜빡임 분석**을 누른다. 실시간 감지는 하지 않는다.
- `/import.html`에서 영상 파일을 고르고 **영상 눈 깜빡임도 이 기기에서 분석 (선택)**을 켜면 종료 후 같은 결과 화면으로 이동한다. 끄고 불러온 영상이나 이전 웹캠 기록도 결과 화면에서 분석할 수 있다.
- 소리를 읽지 못해도 재생 가능한 30분 이하 영상이면 영상만 보관하고 깜빡임 분석을 제공한다. 소리 분석·글자 변환은 건너뛴다.
- 진행률·취소·다시 분석을 제공한다. 로딩·지원·디코딩 실패는 이유를 표시하고 기존 시간·녹음·결과를 유지한다. 모델 로딩 60초, 프레임 읽기 15초, 분석 전체 10분 제한이다.
- 군말 후보는 사용자가 켠 음성 인식·AI 전사 결과가 있을 때 자동 집계한다. 새로운 텍스트 AI 호출은 추가하지 않는다.

## F15 / FR-15 / AC-15: 눈 깜빡임

입력은 `session.videoBlob`이다. `video-analysis.js`가 별도 video 요소를 20Hz로 순차 탐색해 MediaPipe Tasks Vision Face Landmarker 0.10.32의 `eyeBlinkLeft`·`eyeBlinkRight`를 읽는다. 동기 추론 사이마다 이벤트 루프에 양보한다. 원시 얼굴 좌표·프레임은 저장하지 않고 샘플은 계산 뒤 폐기한다.

계산은 DOM/모델에서 독립된 `blinks.js`의 순수 함수 `analyzeBlinks`에 둔다. 기준은 `BLINK_RULES`에 고정하고 화면에 표시한다. 모델이 반환하는 계수는 감정 점수나 확률로 해석하지 않는다.

| 규칙 | 값·처리 |
| --- | --- |
| 표본 간격 | 0.05초(20Hz). 짧은 깜빡임을 놓칠 수 있음 |
| 닫힘 / 열림 | 양쪽 눈 모두 0.6 이상 → 양쪽 모두 0.35 이하로 돌아오면 1회 |
| 닫힌 길이 | 0.04~0.8초. 장시간 감음·처음부터 감음·끝까지 감음·한쪽 눈만 감음 제외 |
| 중복·공백 | 깜빡임 간 최소 0.15초. 프레임 공백 0.15초 초과·얼굴 인식 실패 시 상태 초기화 |
| 유효 얼굴 | 얼굴이 정확히 1개이고 양쪽 계수가 0~1의 유한 숫자인 프레임. 0개·여러 얼굴·계수 누락 제외 |
| 관측 시간 | 유효 프레임당 최대 0.05초를 누적. 건너뛴 시간을 유효 시간으로 채우지 않음 |
| 수치 표시 | 얼굴 관측 5초 이상 AND 전체 영상의 70% 이상. 부족하면 횟수·분당 수치를 숨기고 ‘측정 못 함’과 이유 표시 |
| 분당 횟수 | 깜빡임 수 ÷ 얼굴 관측 시간 × 60. 얼굴 측정 불가 비율과 전체 길이를 함께 표시 |
| 구간 | 10초 단위. 구간 역시 관측 5초·70% 기준을 충족해야 수치 표시 |
| 증가 검토 항목 | 해당 구간을 제외한 같은 영상의 유효 구간이 20초 이상일 때, 그 평균의 2배 이상 AND 분당 12회 이상 증가 AND 3회 이상인 구간 |

‘평소’ 개인 기준은 확보하지 않았다. 따라서 **이번 영상의 다른 구간 평균**이라고 표시하며 평소 습관·긴장·정상/비정상으로 표현하지 않는다. 단일 영상의 다른 사람이 등장하거나 얼굴 각도·조명·안경이 바뀌는 경우 같은 사람·같은 측정 조건임을 보증하지 않는다.

완료 조건 AC-15: 계산 테스트, 모델 로딩, 영상 탐색·저장, 얼굴 미검출·로딩 실패·취소 시 기존 결과 보존이 동작한다. `buildReviewItems({ blink })`가 `type: blink`, 위치·측정값·계산 근거를 만들고 기존 결과의 버튼으로 영상 위치를 이동한다. 실제 사람 정확도는 별도 검증 전 보장하지 않는다.

## F16 / FR-16 / AC-16: AI 전사와 군말 후보

기존 `POST /api/transcribe`를 그대로 활용한다. 키·요청 크기·서버 누적 초 한도·오류 구분·선택 전송 조건을 유지한다. 글자 변환을 켜지 않으면 음성이 외부로 전송되지 않는다. 깜빡임 분석과 AI 전사 선택은 서로 독립이다.

`fillers.js`는 인식된 글을 유니코드 문자·숫자 토큰으로 나누고 `FILLER_WORDS` 사전과 **전체 토큰 일치**로 집계한다. 현재 사전은 음·어·으음·저·그·저기·그니까·그러니까·뭐·이제·약간·사실·um·uh이다. 늘인 음음/어어는 하나의 토큰을 1회로 센다. ‘음악’·‘어머니’ 같은 부분 문자열은 세지 않는다.

총 횟수·종류별 횟수와 해당 전사 구간을 표시한다. 위치는 단어 수준 시각을 만들어 추정하지 않고 **해당 전사 구간 전체**를 사용한다. segments가 없으면 기존처럼 WAV 조각 전체(약 20초)가 위치 근거가 된다. 결과는 실제 군말의 정답이 아닌 **전사문에 남은 후보 횟수**다. 필요한 단어·강조·인용도 포함될 수 있고, 음성 인식이 군말을 생략하면 셀 수 없다. 후보가 없다는 0과 전사 자체가 없는 ‘측정 못 함’을 구분한다. 사용자 교정 대화 F13은 아직 미구현이다.

`cleanSegments`와 `chunkSegments`는 문서상 `startSecond/endSecond`, 기존 호환 `start/end`를 받는다. null·빈 문자열·음수·역전 구간을 0초로 오인하지 않고 제외하며 구간을 시간순으로 정리한다. 소비 측에서 파일 조각 범위를 검사·제한한다. 잘못된 JSON 응답은 502로 처리하고 예약한 누적 초를 반환한다.

완료 조건 AC-16: 선택 자체 전송·worker 없음·한도·오류 흐름과 기존 결과를 유지한다. 실제 전사 토큰의 후보 종류·횟수·구간 근거를 보여 주고 눌러서 이동한다. 자체 worker의 합성 무음 처리는 확인했다. 실제 사람의 군말·전사 구간 정확도는 별도 검증한다.

## 배포·개인정보·의존성

- `public/vendor/mediapipe/0.10.32/`에 SDK·SIMD/비SIMD WASM·모델을 포함했다. npm 런타임 의존성·빌드 단계·외부 CDN은 추가하지 않았다. 약 26.4MB의 원본 정적 파일이다.
- `manifest.json`은 npm tarball integrity와 개별 SHA-256·모델 출처를 기록한다. SDK 라이선스와 출처는 같은 폴더의 LICENSE·NOTICE.md를 참고한다.
- 서버 MIME에 `.mjs`와 `.wasm`을 추가했다. CSP는 `script-src 'self' 'wasm-unsafe-eval'`만 추가하며 `connect-src 'self'`를 유지한다. 일반 JS `unsafe-eval`, CDN 도메인, 외부 얼굴 전송은 허용하지 않는다.
- `session.analysis.blink`에는 집계·구간·기준·인식 누락률만 저장한다. `session.analysis.transcript.fillers`에는 후보 집계를 저장한다. 원본 영상과 결과는 기존 IndexedDB에만 보관한다.
- API 키는 서버 환경변수만 읽고 브라우저·Git·로그에 기록하지 않는다. 이번 개발 환경의 프로세스·사용자·시스템 환경에 키가 없었으며 실제 게이트웨이를 호출하지 않았다.
- main 자동 배포를 피하도록 새 브랜치·PR로 제출한다. PR 생성은 배포 완료를 의미하지 않는다.

## 검증 근거와 한계

- `tests/blinks.test.mjs`: 합성 blendshape 시계열로 1회 집계·한쪽 눈·긴 감음·공백·인식 누락·기준 부족·증가 구간 검증.
- `tests/fillers.test.mjs`: 종류·횟수·부분 문자열 오탐 방지·전사 없음·검토 위치 검증.
- `tests/vision-assets.test.mjs`: 고정 파일 hash·MIME·CSP 확인. 기존 전사·불러오기 검사에 구간 정규화·예약 한도 반환 검증 추가.
- `e2e/media/measurements.spec.ts`: 실제 모델의 빈 프레임 처리, 소리 없는 합성 영상의 미검출, 가짜 모델 계수로 계산→결과→이동→다시 읽기, 모델 실패·취소, 가짜 AI 전사 집계 검증.
- 합성 영상과 가짜 장치 검사는 **실제 사람 눈 깜빡임 검출 정확도·실제 카메라 성능을 검증하지 않는다.** 기준값은 초기 구현 규칙이며 의료·행동 기준이 아니다. 모델이 없는 얼굴을 검출하지 않는 검사와 실제 얼굴의 깜빡임 정확도는 구분한다.

공식 구현 참고: [MediaPipe 웹 가이드](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/web_js), [faster-whisper](https://github.com/SYSTRAN/faster-whisper). 실제 실행 결과와 미검증 항목은 [progress.md](../progress.md)에 기록한다.


현재 자체 실행 방식에서는 기존 Gateway 전사 설명을 사용하지 않는다. 자체 worker·전송 범위·실행 환경은 [파일 불러오기](import-feature.md), 새 텍스트 코칭은 [구현 범위](local-ai-implementation.md)를 따른다. 브라우저 실시간 음성 인식은 비활성화했으며 파일 전사의 군말·속도 계산 규칙은 유지했다.
