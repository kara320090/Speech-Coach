## 3. 기존 문서에서 보존하되 재확인이 필요한 기록

기준 코드의 `problem.yaml`에는 “10분보다 짧거나 11분 이상이면 감점”, “10분 30초 목표”, “10분 미달·11분 초과”라는 구체적 기준이 있었다. 현재 대화에서 확인 가능한 직접 진술만으로는 이 구체 수치와 감점 규칙을 독립적으로 검증할 수 없다. 원래 기록을 여기 보존하고, 문제 정의에서는 일반적인 시간 초과·미달 경험으로 표현한다. 과제 원문 또는 사용자 확인을 받으면 출처와 함께 복원한다.

초기 기준 `086a83a`에는 E2E 파일이 없었지만 작업 중 원격에 추가됐다. `625b942`의 [CI](https://github.com/kara320090/Speech-Coach/actions/runs/40866156494)에서 Docker·health·S1–S4 4개 성공을 확인해 문서를 갱신했다. 별도 가짜 장치 검사 파일도 보존했다. 이 CI는 미디어 별도 설정을 실행하지 않으며 실제 마이크·웹캠·음성 인식 검증은 여전히 남아 있다.
