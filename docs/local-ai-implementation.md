# 자체 AI 첫 구현 — 현재 범위와 남은 차이

## 2026-10-30 AI 처리 역할

새 대본 생성(F22)과 사용자가 별도로 동의해 선택한 상황 대화(F23)는 Gemini 3.8 Flash로 처리한다. F22는 주제·근거만, F23은 선택한 대본·근거·관찰 텍스트·현재 대화 답변만 전송한다. F23은 열린 질문으로 시작하고 쉬운 대본을 만들지 먼저 물으며 확인한 초안만 다음 연습에 적용한다. 기존 `/coach.html`의 개념·수정·질문·답변 검토와 구간 코칭 API는 Qwen, 음성 전사는 faster-whisper를 유지한다. 자동 공급자 대체는 없다. [AI 역할](gemini-coach.md)·[도움 대화 명세](supportive-coach.md)를 따른다.

## 2026-10-30 main 통합 상태

main의 다시봄 화면, TXT 불러오기, 구간 질문·조건 선택·재연습(S9), E2와 공개 조사 기록을 보존했다. 자체 AI 대본 코칭과 선택 전사, 영상 눈 깜빡임을 함께 제공한다. main의 F15는 대본 이해 교차 확인으로 유지하고, PR #3의 눈 깜빡임은 F21로 변경했다. 기존 문서의 미구현 표시는 당시 기록이며, 현재 상태는 이 절과 구현 범위 문서를 따른다. F13–F14 기본 흐름은 구현됐지만 전체 계획 수용 조건이 검증됐다는 뜻은 아니다.

2026-10-29. F7–F20의 전체 기획이 모두 구현된 것으로 표현하지 않는다. 아래는 이번 브랜치의 실제 코드다. 기존 얼굴 측정 PR #3 위에 새 작업 브랜치에서 개발했다.

## 1. 새 화면과 실제 처리

`/coach.html`은 자료 저장→개념 선택→자기 설명→쉬운 대본→질의응답→최근 두 답변 비교를 제공한다. 대본/자료 각각 2,400자, 답변 1,000자를 받아 긴 발표는 구간별로 다룬다. 자동으로 잘라 일부만 평가하지 않는다.

| 기능 | 현재 코드 | 남은 기획 |
| --- | --- | --- |
| F7 | 대본·자료 구분, 불변 버전 기록, 원본 복귀, 별도 IndexedDB | 여러 프로젝트·자료 문단 ID·필수 항목 편집기·녹음 세션 자동 연결 |
| F9 | 자체 모델 쉬운 대본 제안, 원문/제안 비교, 직접 수정, 확인 후 새 버전 | 개인 실측 시간에 맞춘 축약·보완 |

F1–F6의 시간·기록·로컬 측정은 유지한다. 실시간 브라우저 음성 인식은 외부 처리 가능성 때문에 비활성화했다. 녹음 후 파일 불러오기에서 자체 전사로 속도·군말 후보를 계산한다. F21 얼굴 측정은 브라우저 안에 남고 이해·감정 판단에 쓰지 않는다.

| 파일·경로 | 역할 |

계획된 `/api/revisions`, `/api/content-checks`, `/api/concepts`, `/api/explanations`, `/api/questions`를 개별 구현한 것이 아니다. 현재는 `/api/coach`의 과업 분기로 제공한다. 기존 녹음 IndexedDB는 수정하지 않는다. 새 저장소는 `speech-coach-understanding`, store `workspaces`, 현재 작업 1개 안에 버전·답변 이력을 저장한다. 내보내기에는 입력 자료와 본인 답변이 포함된다고 안내한다. 상황 질문·걱정 원문은 아직 수집하지 않는다.

## 3. 모델 결과 처리

입력에 실제 존재하는 문구로 인용 후보를 제한하고 서버에서 재검사한다. 이것은 해당 문구가 주장을 논리적으로 지지한다는 증명이 아니다. 잘못된 JSON·없는 인용·출력 초과·끝나지 않은 출력은 502로 반환해 원본을 보존한다. 대본 변경 중 받은 이전 응답은 화면에서 적용하지 않는다.

검토 모델은 사실 대조를 먼저 수행한다. 사용자에게 보이는 다음 행동은 근거를 다시 설명하게 하는 정해진 문구로 구성한다. 긍정적인 말투를 강하게 요구한 초기 프롬프트가 오답을 맞다고 평가한 사례가 있어 사실 대조와 문구 생성을 분리했다. 최종 `understanding-v4`도 검증된 진단·이해도 측정기가 아니며 사용자 확인/동의하지 않음 상태를 별도로 남긴다.

수치·단위 변화는 적용 차단 대상이다. 수정 초안에서 빠진 값을 사용자가 직접 고쳐야 적용할 수 있다. 부정·조건·한계 검사는 보수적인 문자열 규칙으로 오탐·미탐이 가능하다. 전체 의미 보존은 사용자 확인이 필요하다. 모델 풀이·원자료의 사실성도 자동 보증하지 않는다.

## 4. 확인한 것과 미확인

- Node 22.23.4 단위 69개, 기존 S1–S4 4개, 미디어·코칭 24개 통과. 코칭 검사는 오류·취소·버전·보존·저장·질문 상한을 포함한다.
- Qwen3-4B Q4_K_M·llama.cpp b11960 Vulkan을 32 GB RAM·RTX 4060 Laptop 8 GB에서 실제 실행했다. 가상 한국어 개념·수정·질문·정답/오답·자료 부족 과업과 실제 브라우저 연결을 확인했다.
- 개발용 소수 예시에서 프롬프트를 수정했으므로 정확도·일반화 성능 수치로 보고하지 않는다. 초기 오답 수용·수치 누락·인용 변형을 발견했고 보호 규칙을 보완했다.
- 최종 수정 과업 재확인에서도 `5분`이 빠진 제안이 생성됐고 약 3.93초 만에 누락 경고·적용 차단 결과를 받았다. 수치 보존 지시만으로 생성 품질이 보장되지 않으며 사용자의 직접 보완이 필요할 수 있다.
- faster-whisper 1.2.1·base 고정 모델로 합성 무음 4초 처리: HTTP 200, 빈 전사, 약 0.85초. 실제 사람 음성·한국어 군말 정확도 시험은 아니다.
- 실제 얼굴 정확도·학습 효과·시간 절감·공개 AI 배포·다중 사용자 운영은 미검증이다.

실행 명령과 고정 파일 출처·해시는 [실행 안내](../local-ai/README.md), 전체 기능 목표는 [정의서](requirements-definition.md), 상세 검증은 [검증 계획](validation-plan.md)에 있다.

## F23 구현 범위

결과 링크·대본/관찰 선택·텍스트 전송 동의·Gemini 질문/응답·쉬운 대본 생성 허락·원문/수정안 비교·수치 변경 차단·확인 후 다음 연습 적용·과거 세션 보존·직전 적용 되돌리기를 제공한다. 별도 선택한 F23만 외부 Gemini를 사용하고 기본 Qwen·Whisper 경로는 유지한다. 부정적 판정 문구·자료 밖 인용을 검사하지만 의미·감정·실제 원인을 자동으로 검증하거나 해결 완료를 선언하지 않는다. 실제 Google 호출과 브라우저 가짜 응답 검사는 진행 기록에서 구분한다.
