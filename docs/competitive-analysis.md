# 경쟁 서비스 분석서

조사일: 2026-10-29. 이 문서는 직접 조작 결과, 개발사 설명, 미확인을 구분한다. 조사 당시 웹에서 볼 수 있는 범위이며 경쟁 앱의 모든 버전·유료 기능을 검증한 보고서는 아니다.

## 1. 조사 질문

1. 목표 시간에 맞춰 사용자의 기존 대본을 자동으로 수정하는가?
2. 재연습 전후의 기록·측정값·수정 효과를 비교하는가?
3. 사용자가 직접 해야 하는 판단과 수정이 무엇인가?

시간 표시·시간 배분·시간별 템플릿·분량 조언·실제 문장 자동 수정은 별개다. 기록 조회·점수 추세·회차 나란히 보기·같은 수정 항목의 해결 확인도 구분한다.

## 3. 재현 기록

### C-PT-01: 시간 변경과 대본 수정의 구분

- 개인정보가 없는 2장짜리 가상 대본을 텍스트로 가져왔다.
- 1분 설정을 2분으로 바꾼 뒤 균등 배분했다. 각 장표가 30초에서 60초로 바뀌고 대본은 유지됐다.
- 녹음하지 않고 타이머만 시작·종료했다. 약 27초 후 종료 화면에 목표 2분, 시간 정확도 22/100이 표시됐다.
- 이 점수는 타이머 UI를 확인한 결과다. 실제 발표 품질이나 음성 분석 성능의 평가가 아니다.
- [설정 화면](evidence/ptsandbag_time_controls.png) · [타이머 종료 화면](evidence/ptsandbag_timer_result.png)

### C-SAY-01: 30초·60초 문장 틀의 분량 처리

- 영문 피치 입력란에 대학생의 가상 프로젝트·관심 직무·활동·요청을 입력했다. 본인 경력이나 실제 성과를 전송하지 않았다.
- 30초 버전은 114단어·예상 49초, 60초 버전은 162단어·예상 69초로 표시됐다. 두 버전 모두 사용자가 답변을 줄이라는 안내를 받았다.
- 시간은 도구가 사용하는 140단어/분 기준 예상치다. 실제 발화 시간 측정이 아니며 한국어 성능 평가도 아니다.
- 이 경로는 자동 축약이 아니라 템플릿·길이 안내라는 점을 확인했다.
- [입력·대본 화면 일부](evidence/saynow_time_test.png) · [조작 당시 관찰 기록](evidence/observations.json). 캡처에는 입력·대본 일부가 보이고, 길이 수치와 안내 문구는 조작 당시 접근성 화면에서 확인해 기록했다.

## 4. 확정할 수 있는 결론

- 한국어·개인용·녹음·타이머·구간 재생·회차 비교만으로 고유 차별점을 주장할 수 없다.
- PT샌드백의 확인한 경로는 시간 배분과 수동 대본 편집을 제공한다. 자동 대본 축약과는 구분된다.
- SayNow의 확인한 웹 피치 도구는 초과 분량을 사용자가 줄여야 한다. 앱 전체에 자동 수정이 없다고 말할 수는 없다.
- 세 서비스 모두에 개인 실측 기반 수정·내용 보존·항목별 재점검이 없다는 결론은 **미확인**이다.

## 5. 우리 제품에서 선택한 차별화 방식

구현 결과를 다음 산출물로 명확히 구분한다.

| 사용자가 받는 결과 | 구체적인 제품 기준 | 검증 방법 |
| --- | --- | --- |
| 개인 기준의 수정안 | 실제 발화와 대본의 대응이 확인된 구간에서 시간 차이를 추정하고 문장 수정안을 제시 | F8–F9, 실제 연습 시간과 예상 오차 기록 |
| 필수 내용 보존 근거 | 수정 전후 문장, 필수 항목 ID, 수치·단위·조건·부정 의미의 변화 제시 | F10, 정답이 있는 문장 쌍 테스트 |
| 수정 항목별 결과 | 이전 지적을 다음 발화의 근거에 연결해 해결·미해결·판단 불가 표시 | F11, 원문-수정안-재연습 연결 확인 |
| 전체 발표 확인 | 부분 재연습과 전체 재연습을 구분하고 마지막 전체 실측 결과를 기록 | F11, 전체 시간 범위와 필수 항목 전달 확인 |
| 관찰·본인 설명 기록 | 검토 구간 재생 확인(맞음/잘못 인식/문제 아님), 열린 상황 질문 기본 최대 3개, 관찰·본인 설명·미확인 해석을 분리한 요약 | F13, 오탐·건너뛰기·질문 상한 시험 |
| 대본 이해 교차 확인·다듬기 | 막힌 구간에서 이해 여부를 사용자에게 교차 확인하고, 응답을 반영해 대본을 자연스러운 말로 다듬은 뒤 원문·설명·수정안·재연습 발화를 비교 | F15, 의미 차이·보존 검사·그대로 읽기 구분 시험 |
| 조건 시험 기록 | 선택한 조치 하나(핵심어 카드·전환 문장·구간 진행 표시 등), 바꾼 조건·유지한 조건, 군말 빈도·내용·시간·선택적 부담의 전후 비교, 효과 없음·악화 표시 | F14·F11, 조건 차이·단서 제거 전체 연습 시험 |

이는 기능 부재를 단정해 얻은 시장 독점성 주장이 아니라, 기존 비교 결과를 반영해 선택한 제품 범위다. 우월성·수요·절감 효과는 [검증 계획](validation-plan.md)의 실제 과업 비교로 판단한다.

### 추가로 선택한 제품 과업: 상황 확인과 조건 시험

사용자 제안에 따라 관찰 구간을 확인하고, 당시 어려움을 질문한 뒤, 핵심어 단서·화면·연습 조건 중 하나를 바꾸어 재연습에서 확인하는 흐름을 F13–F14로 계획했다. 상세는 [코칭 설계](coaching-design.md)를 따른다. 목표 시간에 맞춘 대본 수정은 이 흐름에서 필요한 경우 선택하는 조치다.

이번 경쟁 조사는 목표 시간 대본 수정과 전후 비교에 집중했다. 세 서비스에 대본 이해 확인·자연스러운 대본 다듬기(F15) 기능이 있는지도 조사하지 않았으므로 “경쟁사에 없다”고 쓰지 않는다. PT샌드백·Talkli·SayNow에 원인 질문·준비 환경 조정 코칭이 있는지는 별도로 검증하지 않았다. 따라서 이 방향도 “경쟁사에는 없다”거나 “효과가 검증됐다”는 차별점으로 단정하지 않는다. 구체적인 제품 과업은 확정했으며 독점성·우월성은 미확인이다. 이 부분을 확인하려면 각 서비스의 공식 자료나 실제 조작에서 결과 화면 이후의 질문·조건 변경 흐름을 확인하고, 확인한 경로·날짜·요금제 범위를 이 문서에 추가한다.

## 6. 홍보·기획 문구 규칙

사용 가능: “발표에서 막힌 순간을 함께 확인하고, 준비와 연습 조건을 바꾸어 다시 점검하도록 돕는 웹 서비스.” 개발 전에는 “개발 예정”을 함께 적는다.

사용 불가: “국내 유일”, “경쟁사는 전후 비교가 없다”, “AI가 반드시 목표 시간에 맞춘다”, “10시간을 자동으로 절약한다”, “감점을 방지한다”. 한 리뷰의 불만을 전체 제품의 품질로 일반화하지 않는다.
