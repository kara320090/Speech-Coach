# AI 연결 없이 체험하는 예시 화면

`/demo.html`은 Docker에서 모델·키·마이크·카메라가 없어도 코칭의 화면 흐름을 체험할 수 있는 인터랙티브 목업이다. 메인과 스튜디오의 **시연용 예시 체험**으로 진입한다. 기본 Docker의 정적 파일로 제공하며 추가 모델 다운로드가 필요 없다.

화면 상단에 **시연용 예시 · AI 호출 없음**을 계속 표시한다. 대본, 0:18–0:22의 멈춤 후보, 코칭 답변과 수정 초안은 미리 작성한 가상 예시다. 녹음·AI 추론의 실제 결과나 효과 검증으로 사용하지 않는다. API 요청은 보내지 않는다.

## 체험 흐름

1. 준비된 대본에서 **예시 분석 보기**를 누른다.
2. 관찰 예시와 함께 볼 대본 부분을 확인한다.
3. 표현의 뜻, 다음 문장 단서, 청중에 대한 신경 쓰임, 의도한 쉼 중 사용자가 상황을 고른다. 멈춤만으로 원인을 선택하거나 감정을 진단하지 않는다.
4. 상황에 맞는 준비된 도움말을 보여 준다. 표현의 뜻을 선택하면 쉬운 대본 예시를 볼지 먼저 묻는다. 다른 선택은 핵심어 단서·시작 환경·원문 유지로 이어진다.
5. 별도 허락 후 원문과 수정 예시를 나란히 보여 준다. 사용자가 직접 고칠 수 있고, 5분이라는 수치와 원래 뜻을 확인해야 적용할 수 있다. 수치 변경은 기존 보존 검사로 차단한다.
6. 적용·새로고침·원문 복원을 체험한다. 원문과 적용 버전은 함께 남는다.

저장은 `localStorage`의 `dasibom.offline-example.v1`에만 한다. 실제 연습 IndexedDB·녹음·대본을 변경하지 않는다. 저장이 불가능하면 현재 화면에만 보관한다고 안내한다. **예시 처음부터**는 예시 상태만 초기화한다.

## 제출 검사

`docs/scenarios.yaml`의 S7와 `e2e/scenarios/S7.spec.ts`가 위 흐름을 실제 화면 조작으로 확인한다. API 가로채기·가짜 API 응답·테스트 건너뛰기를 사용하지 않는다. 적용 전 확인, 새로고침 보존, 원문 복원, API POST 0건을 검증한다.

기본 제출 흐름은 S1–S7·S9의 8개다. 이 예시의 통과는 모델 추론·음성 인식·감정 파악의 정확도를 검증한 것이 아니다. 실제 AI 경로와 실행 환경은 [Gateway 안내](ai-gateway.md), [자체 AI 실행 안내](../local-ai/README.md)를 따른다.
