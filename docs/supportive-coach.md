# F23 — 상황을 먼저 묻는 Gemini 발표 코칭

사용자 지시(2026-10-30)로 Gemini 3.8 Flash의 역할을 새 대본 생성과 별도로, 사용자가 선택한 도움 대화까지 확장한다. 기존 `/api/coach`와 구간 코칭 API·전사는 Qwen·Whisper를 유지한다. 자동 공급자 전환은 없다.

## 통합 화면(2026-10-30): 자체 AI 구간 대화와 한 화면

결과의 검토 구간 질문 카드에서 **대본 위치 확인하고 AI와 이야기하기**를 누르면(또는 구간을 고른 뒤 **대본과 함께 AI 코칭**) 같은 `/support-coach.html?session=...&item=...`이 열린다. 비슷한 두 흐름(이 문서의 Gemini 도움 대화, 자체 AI 구간 대화)을 한 화면으로 합쳤다.

1. **대본 위치 확인**: 녹음 전사가 있으면 `/api/scripts/align`이 이 구간과 가까운 문장을 추천하고, 사용자가 확인하거나 다른 문장을 직접 고른다(`matched`라도 확인 전에는 대화하지 않음). 전사가 없으면 문장 목록에서 직접 고른다. 확인한 문장이 있는 **문단**을 함께 볼 대본으로 가져온다.
2. **대화할 AI 선택**: 기본은 **자체 AI**(`/api/coach/segment`, 외부 전송 없음). 원하면 **Gemini**(아래 기존 흐름, 전송 동의 필요)를 고를 수 있다. 공급자·모델·환경변수는 바꾸지 않았다.
3. **자체 AI 대화**: 상황 질문 → 선택지·직접 입력·잘 모르겠어요·설명해 주세요·여기까지 정리하기. 후속 질문 최대 3회.
4. **문단 수정**: 대화가 끝나면 **이 문단 고치기**를 눌렀을 때만 `/api/scripts/revise-segment`를 호출한다. 수정 불필요·추가 확인이면 그 이유와 선택지를 보여 준다.
5. **비교·적용·다시 연습**: 아래 기존 화면(원문·초안 비교, 보존 확인, **수정본으로 다음 연습 준비**, 되돌리기)을 그대로 쓴다. 자체 AI 수정안은 적용 직전 대본 버전·원문 해시를 다시 확인하고, 그 문단만 바꾼 다음 연습 대본과 새 대본 버전을 만든다. 지난 녹음·당시 대본은 바꾸지 않는다.

연습 기록·검토 구간 없이 열면(예: 직접 대본 입력) 자체 AI 구간 대화는 비활성화되고 기존 Gemini 흐름만 쓴다. 결과 화면의 기존 질문 카드(조건 선택·재연습)도 그대로 유지한다.

## 화면과 실제 흐름

결과의 **대본과 함께 AI 코칭** → `/support-coach.html?session=...&item=...`에서 당시 대본과 관찰 후보를 가져온다. item이 없으면 최대 8개를 표시한다. 위치와 맞는지는 사용자가 확인하고 보낼 관찰을 선택 해제할 수 있다. 녹음이 없는 경우 대본·직접 설명만 사용하며 미측정 상태를 원인으로 바꾸지 않는다. 긴 대본은 2,400자 이내 부분을 직접 선택한다.

1. Google로 보낼 텍스트 범위를 읽고 동의한 다음 **동의하고 함께 살펴보기**를 누른다.
2. Gemini가 대본·선택한 관찰을 함께 보고 열린 질문 한 개로 시작한다. 처음부터 암기 부족·긴장·이해 부족을 고르도록 강요하지 않는다.
3. 본인이 상황을 설명하면 그 말에 맞춰 풀이·핵심어·다음 문장 단서 등 다음 행동 하나를 제안한다. 후속 답변은 최대 3회다. 모름·중단을 존중한다.
4. 표현을 풀어 보고 싶다는 답에 따라 **쉬운 표현을 함께 만들까요?**라고 의사를 묻는다. **지금 대본을 유지할게요**에는 생성 요청을 보내지 않는다.
5. **네, 쉬운 대본을 제안해 주세요**를 누른 경우에만 수정 초안을 생성한다. 원문·수정문·이유를 나란히 보여 준다. 수치·단위 변경은 차단하고 조건·부정·한계는 경고와 사용자 확인으로 보완한다. 의미 동등성을 자동으로 보증하지 않는다.
6. 의미 확인 후 **수정본으로 다음 연습 준비**를 누르면 선택 부분만 바꾼 다음 연습 대본을 준비한다. 기존 녹음·측정값·당시 대본은 유지하고 자체 AI 이해 연습의 버전·기존 답변도 보존한다. 직전 적용은 되돌릴 수 있으며, 이후 대본이 달라졌다면 자동으로 덮어쓰지 않는다.

## 대화 예시 — 설계용 가상 문장

| 본인의 말 | 코치가 도울 방향 |
| --- | --- |
| “캐시라는 말을 제 말로 설명하고 싶어요.” | 제공 자료의 저장·재사용 뜻을 짧게 풀고, 어려운 표현을 쉬운 대본으로 바꿀지 먼저 묻는다. |
| “내용은 알지만 다음 문장이 순간 생각나지 않았어요.” | 외우라고 지적하기보다 다음 구간의 핵심어·첫 문장 단서를 두고 다시 말하도록 제안한다. |
| “청중을 보니 긴장됐어요.” | 본인이 말한 느낌으로만 기록하고 어느 순간 신경이 쓰였는지 묻는다. 시선 위치나 시작 전 준비 등 바꿔 볼 조건을 함께 고른다. |
| “일부러 쉬어 간 거예요.” | 침묵을 고칠 문제로 확정하지 않는다. 원치 않는 수정은 하지 않는다. |

## API·전송·보관

- `GET /api/coach/support-status`: 설정·최근 연결 상태. 외부 생성 요청 없음.
- `POST /api/coach/support`: `support-start`, `support-answer`, `support-rewrite`. 대본·자료 각각 2,400자, 상황 600자, 관찰 8개·각 300자, 순서가 맞는 대화 최대 7항목·각 1,600자, 본문 64KiB. 요청·대본 버전 ID를 확인한다.
- 모든 실행에 `externalTransferConsent: true`, 수정에 `rewriteConsent: true`와 앞선 본인 답변을 요구한다. 공개 API의 동의 필드는 사용자 신원 인증을 뜻하지 않는다.
- 허용된 텍스트만 Google Gemini로 전송한다. 음성·영상·얼굴·API 키는 브라우저 요청 본문에 포함하지 않는다. 키는 기존 서버 `GEMINI_API_KEY`, 모델은 `GEMINI_MODEL`(기본 `gemini-3.8-flash`)이다.
- 기존 Gemini 클라이언트·출력 크기·취소·오류 분류·동시 처리·메모리 호출량 제한을 재사용한다. 도움 대화의 `SUPPORT_GEMINI_TIMEOUT_MS`는 기본 105초·최대 110초로, [Vercel 외부 프록시의 120초 한도](https://vercel.com/docs/limits#proxied-request-timeout) 안에서 오류 응답 시간을 남긴다. 새 대본의 55초 설정과 분리한다. 지원 대화의 기본 기기별 분당 한도는 6회다. 각 서비스의 제한은 별도이고, 재시작·다중 인스턴스의 합산 예산을 보장하지 않는다.
- 대화는 해당 탭의 sessionStorage, 적용한 대본 버전은 브라우저 IndexedDB, 다음 연습 설정과 직전 되돌리기는 localStorage에 둔다. 서버는 대화·대본·음성을 파일·DB·본문 로그로 저장하지 않는다. Google 측 처리는 해당 API 조건을 따른다.
- 키 없음·모델 접근 오류·한도·시간 초과·잘못된 출력·취소에도 원문·입력 답변을 유지한다. 모델 결과를 다른 AI나 규칙 응답으로 속여 대체하지 않는다. 기본 녹화·자체 AI는 별도다.

## 검사 범위

`tests/support-coach.test.mjs`: 전송 동의·수정 허락·질문 상한·거절·원문/수치 보존·긴 대본·부정적 판정 차단·근거 인용·오류·API 경계. `e2e/media/support-coach.spec.ts`: 결과에서 진입·처음 질문·본인 답변·허락 후 생성·확인 후 적용·이전 녹음 보존·되돌리기·취소·키 없음. 브라우저 검사는 가짜 공급자 응답과 장치를 쓰므로 실제 Gemini 품질·학습 효과 증거와 구분한다.

키가 필요한 선택 기능이므로 제출 8개 기본 시나리오에 필수로 넣지 않는다. 기존 무키·무장치 Docker 흐름과 자체 모델 검사를 유지한다. 실제 공개 Gemini 호출 결과는 `progress.md`에 별도로 기록한다.

Gemini 3.8은 지원되는 low thinking을 사용하며, [공식 마이그레이션 안내](https://ai.google.dev/gemini-api/docs/generate-content/whats-new-gemini-3.8)에 따라 3.6+ 모델에는 폐기 예정인 sampling 인자를 보내지 않는다. 모델·과금 등급을 자동 변경하거나 생성 요청을 자동 반복하지 않는다.

### Gateway 공급자와 구간 대화 UI
구간 대화/자유 대화는 사용자 흐름의 구분이며 공급자 선택이 아니다. 실제 공급자는 서버 설정을 따른다. 화면은 `/api/model-status`와 도움 대화 상태의 실제 모델·처리 안내를 사용한다. 외부 처리에서는 전송 동의 후에만 구간 대화·문단 수정 요청을 보낸다. 녹음 전사의 조각 단위 `timingPrecision`은 위치 확인 API에도 전달한다. 화면 연결은 별도 `support-coach.html`에서 이루어지며, 메인 영상 아래 인라인 채팅은 아직 아니다.
