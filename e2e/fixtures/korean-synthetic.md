# 합성 한국어 전사 입력

`korean-synthetic.wav`는 연결 검증을 위해 Windows 한국어 TTS로 만든 16kHz 모노 PCM WAV(약 8.72초)다. 사람의 음성·얼굴·개인정보를 포함하지 않는다.

내용: 발표 연습을 돕는 서비스입니다. 캐시는 이전 결과를 잠시 저장했다가 다시 사용하는 공간입니다.

S7은 이 파일을 실제 자체 전사 모델로 처리하며 인식 문자열·속도·군말 후보·저장 상태를 확인한다. 인식된 군말 0회는 입력 전사문에서 후보가 없다는 뜻이고, 사람의 군말 인식 정확도나 실제 발화 평가를 뜻하지 않는다.
