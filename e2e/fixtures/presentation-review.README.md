# 실제 발표 영상 테스트 입력

`presentation-review.mp4`는 사용자가 저장소의 채점 시나리오 입력으로 제공한 영상이다.
원본 `KakaoTalk_Video_2026-10-30-07-23-13.mp4`를 수정 없이 복사했다.

- 길이: 약 17.884초, 1280×720 H.264 영상 + AAC 소리, 약 2.3 MB
- SHA-256: `fefb7b6601fc426e8d7441a04add2dd01b110a8cf477bf74e298ba299f9d51f4`
- S6가 파일 선택 UI로 읽어 브라우저에서 디코딩하고 실제 MediaPipe를 실행한다.
- 미리 만든 분석 결과·전사·점수는 포함하지 않는다. 0회 깜빡임도 허용하며 정확도 정답으로 취급하지 않는다.
- 얼굴 프레임은 서버/API로 보내지 않는다. S6는 음성 전사도 끈 상태로 실행하므로 유료 요청이 없다.
- 짧은 영상이라 긴 기준 구간이 필요한 깜빡임 증가 추세 검증에는 적합하지 않다.
- 이 파일은 e2e 입력이다. `.dockerignore`의 e2e 제외를 유지하며 앱 이미지에 공개 영상으로 배포하지 않는다. 테스트 실행자가 저장소의 파일을 브라우저 파일 선택기에 제공한다.
